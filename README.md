# qa-board-node

Вопросы, теги и задачи с авторизацией · *Q&A + todo web app*

`Node.js` `Express` `PostgreSQL` `JavaScript`

```bash
cd backend && npm install && node server.js
```
Перед запуском выполнить `backend/database.sql` и заполнить `.env` по образцу `.env.example`. Открыть http://localhost:3000/frontend/index.html
